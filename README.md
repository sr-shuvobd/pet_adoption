# 🐾 Pet Adoption Platform

A full-stack Pet Adoption web application where users can add pets, send adoption requests, manage requests, and adopt pets easily.

The project is built with modern technologies like Next.js, Express.js, MongoDB, Better Auth, and JWT Authentication.

---

# ✨ Features

- 🔐 User Authentication
- 🔑 JWT Authentication
- 🌐 Google Login
- 🐶 Add New Pet
- ✏️ Edit Pet Information
- ❌ Delete Pet
- 📩 Send Adoption Request
- ✅ Confirm Adoption Request
- 🚫 Cancel Adoption Request
- 📊 Dynamic Dashboard
- 🔍 Search & Filter Pets
- 📱 Fully Responsive UI
- 🛡️ Protected Routes

---

# 🛠️ Technologies Used

## Frontend

- Next.js
- React.js
- Tailwind CSS
- Hero UI

## Backend

- Express.js
- MongoDB
- Better Auth
- JWT
